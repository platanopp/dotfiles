# What this repo tracks, as paths relative to $HOME.
#
# The shell, the Hyprland configuration it runs on, and the theming that makes
# the rest of the desktop match it -- nothing else. It is published for anyone
# to install the shell from, so the user's own programs (their terminal and
# editors, chat, torrents, music) are not in it: those are backed up in a
# private repository of their own, ~/dotfiles-private, which is never pushed.
#
# An allowlist, not a denylist. ~/.config is 1.5 GB and most of it is state:
# browser profiles, Electron caches, session tokens, game saves. Listing what
# to keep means a new app dropping a token in there is out by default; a
# denylist would have been one forgotten entry away from publishing it.
#
# Lines are paths. Blank lines and # comments are ignored.

# ── The shell and the compositor it runs on ──────────────────────────────
.config/quickshell
.config/hypr

# ── Cursor ───────────────────────────────────────────────────────────────
#
# Posy's Improved Cursor, from github.com/simtrami/posy-improved-cursor-linux
# (CC BY-NC 4.0). The whole set is eight themes and 76 MB; only the two
# hyprland.lua actually names are kept here, because that is what a restored
# machine needs to come up on the right pointer rather than the fallback. To
# get the other six back, clone the repo and copy them into
# ~/.local/share/icons.
#
# The -hyprcursor one is generated: `hyprcursor-util --extract` then
# `--create` over the XCursor form, which is all upstream ships.
.local/share/icons/Posy_Cursor
.local/share/icons/Posy_Cursor-hyprcursor

# ── Theming: GTK and Qt applications in the shell's colours ──────────────
#
# gtk-3.0 by file: its bookmarks are this user's folders and network shares,
# and go with the private repository.
.config/gtk-3.0/gtk.css
.config/gtk-3.0/settings.ini
.config/nwg-look
.local/share/themes/Adwaita-dark
.local/share/icons/Papirus-Dark-Grey
.config/qt5ct
.config/qt6ct
.config/kdeglobals
