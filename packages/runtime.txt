# What this configuration calls at runtime, by name.
#
# Separate from pacman.txt on purpose. That file is what the machine happened
# to have installed explicitly; this one is what the shell would break without.
# Three of these were installed only as somebody else's dependency, so a fresh
# machine would have got them by luck rather than by asking -- and when that
# luck changes, what breaks is a widget, quietly.
#
# imagemagick   the wallpaper cropper (scripts/wallpaper_crop.py)
# lua           the keybind cheatsheet reads hyprland.lua with it
# libpulse      pactl, for the per-application volume list
# xdg-utils     opening the vault from the notes widget
# fontconfig    fc-cache, so newly installed fonts are seen
# hypridle      screens off and the lock after idle (hypr/hypridle.conf)
# wlopm         powers the panels off and on (hypr/scripts/idle-screens.sh)
# ddcutil       switches the side display off over DDC in the same script;
#               needs the i2c-dev module loaded (modules-load.d)
# ffmpeg        stills of the video wallpapers (scripts/video_wallpaper.py)
# python-pillow thumbnails for the wallpaper carousel (scripts/wallpaper_thumbs.py)
# qt6-5compat   OpacityMask, for the album art and the lock screen's card;
#               without it MediaWidget and LockScreen fail to load at all
# python-numpy  the bar's spectrum (scripts/spectrum.py)
# python-gobject  osu-mpris.py publishes on D-Bus through it
# wl-clipboard  wl-copy, copying a result out of the launcher
# libnotify     notify-send, when a recording starts and stops
# zenity        the recorder's folder picker
# cava, btop, tty-clock  the three terminal widgets hyprland.lua opens
# tailscale     its tray icon, started from hyprland.lua
# thunar        the file manager hyprland.lua binds to Super + E
